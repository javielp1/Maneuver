# MANEUVER

MANEUVER is a fitness community app I'm developing for my COMP 306 Mobile App Development course at Ithaca College.

The idea behind MANEUVER is to give trainers and clients one place to connect. Members can explore community posts, find trainers, view upcoming events, and access training services.

## Sprint 1

For the first sprint, I'm focusing on the app's interface and navigation. The goal is to get the main screens working before adding the actual features.

The current prototype includes:
- A community feed with sample trainer posts
- Trainer profiles and training services
- A booking screen
- Upcoming events
- Private group previews
- Guest browsing with sign-up prompts

The app currently uses sample data. Booking, payments, and account registration are not functional yet.

## Built With

- React Native
- Expo
- TypeScript
- Expo Router

## Running the Project

Install the dependencies:

```bash
npm install
```

Start Expo:

```bash
npx expo start
```

Open the project using Expo Go on your phone.

As I continue developing MANEUVER, I plan to add user accounts, client booking and payments, and more community features.
